## Project Overview
Card with animated gradient border that rotates and bounces on hover.

## Key Features
- Rotating gradient border using CSS @property
- Bounce animation with translateY effects
- Hover-activated animations
- Responsive design

## How It Works
1. CSS custom property --rotate controls border rotation
2. Hover triggers bounce animation
3. Transitions handle smooth color and shadow changes
4. Media queries adjust for mobile

## Technologies Used
- HTML5
- SCSS/CSS3
- CSS Custom Properties
- CSS Animations

## Learning Outcomes
- CSS @property for animatable variables
- Conic gradients for borders
- Animation performance optimization
- Responsive animation design

## Setup Instructions
1. Open index.html in browser
2. Hover over card to see animations
3. Works on modern browsers

## Performance Features
- will-change for optimization
- animation-play-state for control

- Minimal DOM manipulation
