# Day 12 - Image Hover Animation

Interactive name list with image reveal on hover.

## Features
- Hover on names to reveal profile images
- Images follow cursor movement
- Smooth opacity transitions
- Blend mode text effects
- Responsive design

## Tech Used
- HTML5
- SCSS
- JavaScript
- Mouse Events
- CSS Transitions
- Blend Modes

## Functionality
- Mouseenter shows image
- Mouseleave hides image
- Mousemove tracks cursor
- Element-relative positioning
- Centered image display

## Learning Outcomes
- Mouse event handling
- Dynamic element positioning
- Coordinate calculations
- CSS blend modes
- Image reveal animations
