# Day 18: CSS Anchor Positioning

## Daily Progress
Day 18 of learning - CSS Anchor Positioning experiment

## Project Overview
Interactive colored boxes with dynamic anchor overlay

## Key Features
- CSS Anchor Positioning API
- Hover scaling effects
- Dynamic anchor resizing

## How It Works
1. Default: Anchor covers full screen
2. Hover box: Anchor shrinks to box size
3. Boxes scale up/down on hover

## Technologies Used
- HTML5
- SCSS/CSS3

## Learning Outcomes
- Experimental CSS Anchor Positioning
- :has() selector usage
- Smooth animation techniques

## Setup Instructions
1. Enable Chrome flags: `chrome://flags`
2. Turn on "Experimental Web Platform features"
3. Open `index.html`
